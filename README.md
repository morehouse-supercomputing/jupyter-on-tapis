# Launching Jupyter via Tapis

A step-by-step guide for launching Jupyter Notebook on TACC Vista through the **Morehouse Tapis web interface** (the `jupyter-hpc-native` app). No SSH, no tunnels, all in the browser.

**Guide:** [View the tutorial](https://morehouse-supercomputing.github.io/jupyter-on-tapis/)

## What's covered

- Verifying your TMS keys (the most common reason the job fails)
- Submitting the `jupyter-hpc-native` app with a three-line JSON request
- Finding your Jupyter URL in `tapisjob.out`
- Troubleshooting the `STAGING_INPUTS` hang and other common issues
